# Edge 3.5.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade `edge-version/` from 3.0.0 to 3.5.0 by syncing Chrome runtime code, preserving Edge store metadata and locales, updating store docs/screenshots guidance, and leaving a rollback-safe backup.

**Architecture:** Use two small Node validation scripts under `tests/edge/` to define the expected 3.5.0 runtime and store metadata before changing production files. Then back up `edge-version/`, sync the Chrome 3.5.0 runtime files into it, patch Edge-only files (`manifest.json`, `_locales`, packaging, docs), and finish with repeatable validation commands.

**Tech Stack:** Vanilla HTML/CSS/JS, Chrome/Edge Manifest V3, Node.js built-in modules (`fs`, `path`, `assert`), macOS shell commands (`cp`, `rsync`), PowerShell packaging script for Edge submission.

---
